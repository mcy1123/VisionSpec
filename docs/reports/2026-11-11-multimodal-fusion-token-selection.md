# 多模态融合与视觉 token 选择：128f1x 9k 之后的架构探索（2026-11-11）

## 1. 起点

正结果：**128f1x 原生 9216 token**（16 unique 帧各复制 8×，384×288），E2E-TV 10 updates，fresh30 **3.8796 / 3.8740（两 seed）**，blank 2.8428，reliance 1.037，30/30 逐 token 无损。本报告只在这条正结果上做选择/融合对照，所有 arm 同 target fp32、同 fresh30、同 b63 k8、逐 token 无损门禁。

## 2. 视觉 token 数曲线：不是越多越好，但 128 帧的 9k 不可简单减半

| 输入 | 视觉 token | 训练后 τ | 备注 |
|---|---:|---:|---|
| 16f1x（原 1k） | 1152 | 3.7595 | E2E10 |
| 32f1x（2× 帧复制） | 2304 | 3.7475 | 单 seed |
| 64f1x（4× 帧复制） | 4608 | 3.6757 | 单 seed |
| **128f1x（8× 帧复制）** | **9216** | **3.8796 / 3.8740** | 两 seed |

- 32/64 没有复现 128f1x 的收益，64 甚至低于 1k；**只有 128 帧/9216 token 的完整设置稳定到 3.87–3.88**。
- 32/64 为单 seed，差异（0.07–0.10）不能排除 seed 噪声；但 128 的两 seed 一致，说明 9k 的收益不是单点。

## 3. 视觉 token 选择：减半会掉，不能“白拿”

用 **128f1x 训练出的 head** 直接跑更少 token 的输入（不重训）：

| 输入 | head | τ | 相对同输入训练 head | 相对 128f1x |
|---|---|---:|---:|---:|
| 64f1x (4608) | 64f1x step10 | 3.6757 | — | −0.204 |
| 64f1x (4608) | **128f1x step10** | **3.7004** | +0.025 [−0.016,+0.066] | −0.179 |
| 32f1x (2304) | 32f1x step10 | 3.7475 | — | −0.132 |
| 32f1x (2304) | **128f1x step10** | **3.7358** | −0.012 [−0.060,+0.043] | −0.144 |

- 9k head 对 64/32 输入略有迁移（+0.025 / −0.012），但**不能恢复 128f1x 的 3.88**；减少到 4.6k 损失约 0.18，2.3k 损失约 0.14。
- 结论：**视觉 token 选择/截断不是免费加速**；128f1x 的收益依赖完整的 9216-token 视觉上下文，而不是“随便选一半”。

## 4. 特征融合：target 层 gate

在 128f1x 上给 5 个保留层（1/9/17/25/33）加零初始化 layer gate，训练 10 updates：

| arm | τ | 相对 128f1x |
|---|---:|---:|
| 128f1x step10 | 3.8796 | — |
| + layer gate | 3.8751 | **−0.0045 [−0.020,+0.011]** |

- layer gate 的最后一层权重范数仅 0.004–0.007，bias 变化 <0.001；10 updates 下 gate 基本仍接近 1。
- **target 层 gate 在这个预算下中性**，没有可测收益；不是“学不会”，而是步数/信号不足以让零初始化 gate 偏离 1。
- 静态看 head `fc` 的层权重：layer1 **1064.5**、layer9 753.8、layer17 876.1、layer25 676.2、layer33 **339.1**——**早层特征在投影中占主导**，layer33 最弱。

## 5. 跨层融合 xattn / 视觉特征因果

- xattn：跨层 cross-attention（零初始化输出），10 updates；结果见 5.1。
- zero-visual：推理时把 head 看到的视觉 token 的 target_hidden 置零，文本保留；结果见 5.2。

## 5.1 跨层 xattn：中性

| arm | τ | 相对 128f1x |
|---|---:|---:|
| 128f1x step10 | 3.8796 | — |
| + xattn（10 updates） | 3.8725 | **−0.0070 [−0.0417,+0.0249]** |

- xattn 的 `xattn_out` 权重范数已到 1.29，layer embedding 0.016–0.019，说明模块确实被训练；但 τ 仍中性。
- 与 layer gate 相同结论：**零初始化跨层融合在 10-update 预算下没有可测收益**。

## 5.2 视觉特征因果：zero-visual 诊断

推理时只把 **head 看到的 visual-token target_hidden 置零**，文本和 target 计算不动，测 head 对视觉特征的因果依赖（fresh30，30/30 无损）：

| arm | τ | 相对 real |
|---|---:|---:|
| 128f1x real | 3.8796 | — |
| zero-visual（head 直连视觉特征置零） | **3.6315** | **−0.2481 [−0.373,−0.144]** |
| blank（无视频输入） | 2.8428 | −1.0367 |

- 直接置零视觉 token 只掉 **0.248**，远小于 blank 的 **1.037**；说明 **~76% 的视觉依赖已经进入文本/上下文 target_hidden**，draft head 不是只靠视觉 token 行读取视频信息。
- 逐题变化不均：5 条掉 >0.4，最大 v_2fzIi1lPd8U 8.97→7.48（−1.49）；有的题几乎不变（如 v_1d_U_2HIPmY 3.577→3.577）。视觉特征对部分题是强因果，对另一些题可由文本上下文代偿。
- 架构含义：**只在视觉 token 上做选择/融合，会漏掉大部分视觉信号**；融合应发生在 target 上下文层面（或同时保留视觉 token + 文本上下文两条路）。

## 5.3 优化权重：E2E-TV 10 → 20

同 128f1x、同 10 updates、同 lr/seed 不同，只把 E2E-TV 权重从 10 提到 20：

| arm | τ | 相对 TV10 |
|---|---:|---:|
| TV10（seed1） | 3.8796 | — |
| **TV20** | **3.9046** | **+0.0250 [−0.0020,+0.0524]** |

- 30/30 逐 token 无损；均值为目前最高，但 CI 刚跨零，且单 seed，不能称显著。
- 说明 **优化目标权重** 仍有小幅空间；这是比零初始化融合更直接的收益来源。
- blank：TV20 **2.7970**（30/30 无损），real−blank reliance **1.1075** > TV10 的 1.0367；TV20 同时提高了绝对接受长度和视觉依赖。

## 6. 当前结论

1. **128f1x 9k 仍是目前最好的多模态设置**（3.8796/3.8740），32/64 减 token 不复现。
2. **视觉 token 选择/减半有明确代价**：64f1x 少 0.18，32f1x 少 0.14；9k head 迁移不能弥补。
3. **简单零初始化层融合（layer gate）10 updates 中性**；早层特征权重最大，但门控未学到可测增益。
4. 高 token 的收益更像**完整长视觉上下文**，不是“多 token 本身”；选择融合需要更强监督/更长训练，而不是直接截断。
5. 层 gate 与 xattn 两个融合臂都中性；这不是“融合没用”，而是**零初始化模块 + 10 updates 的预算不足以偏离恒等映射**。
6. **TV 权重 20 把均值推到 3.9046（+0.025，CI 刚跨零）**，是目前最高；优化权重比零初始化融合更快见效，但需第二 seed 确认。
