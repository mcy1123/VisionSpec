## 1. 论文的目标函数（原文公式，逐条抄录）

记一个 block 内被接受的前 `r_m` 个位置为 `I_acc`，被拒后缀为 `I_rej`：

```
I_acc = {(m,k) : 1 <= k <= r_m}                    (Eq 8)
I_rej = {(m,k) : r_m < k <= K}                     (Eq 9)
```

**接受位置 —— 全词表 forward KL，位置权重为朴素均值（无衰减）：**

```
L_acc = (1/|I_acc|) * Σ_{(m,k)∈I_acc} D_KL( p_{m,k} || q_{m,k} )        (Eq 10)
```

**拒绝位置 —— 全词表 reverse KL，带位置衰减并按权重归一：**

```
L_rej = (1/Z) * Σ_{(m,k)∈I_rej} w_k * D_KL( q_{m,k} || p_{m,k} )        (Eq 11)
Z     = Σ_{(m,k)∈I_rej} w_k
w_k   = γ^(k-1)                                                          (Eq 12)
```

**总目标 —— 两个已各自归一的分量做加权平均：**

```
L_Draft-OPD = (λ_acc * L_acc + λ_rej * L_rej) / (λ_acc + λ_rej)          (Eq 13)
λ_acc = λ_rej = 1                                     （实验全部如此设置）
γ = 0.8                                               （Appendix A）
```

Appendix B 的推导明确写出 `D_KL(p||q) = Σ_{y∈V} p(y) log(p(y)/q(y))`（Eq 15–16）与
`D_KL(q||p) = Σ_{y∈V} q(y) log(q(y)/p(y))`（Eq 18），**求和范围是完整词表 V**。
且 Appendix B 明确：接受位置是 target-weighted（Eq 14），拒绝位置是 draft-weighted（Eq 17）。

### 2.1 两处必须点名的分歧

**(a) 论文是「两流各自归一后再平均」，官方代码是「池化加权均值」。**
两者仅在 `|I_acc| == Z_rej` 时相等，一般情况下不等。本项目**按论文 Eq 13**，
因为我们的目标是复现论文语义而不是复现 verl 的分布式 aggregate 实现
（后者的池化形式与它跨 DP rank 做 `_global_sum` 的计数归约耦合，见 `:849–888`）。

**(b) 官方代码的默认 loss 路径是「采样 token 估计量」，不是论文的全词表 KL。**
`_local_bernoulli_forward_kl` 把分布二值化成 {采样 token, 非该 token}；
`kl_penalty(k3)` 是 `r - log r - 1`（`r = p/q`）的单样本估计量。
这是 verl 集成侧只拿到采样 token logprob 时的近似。**论文 Eq 10/11 与 Appendix B 明确是
全词表 V 的 KL**，本项目按论文实现全词表。

> 这一条同时解释了历史 2×2 实验为什么「rejected reverse-KL stream 为空」：
> 那不是论文语义，而是旧实现只做首个拒绝位置的 top-k forward KL。

## 3. 论文未规定、必须由我们显式定义的规则

论文对以下情况没有给出规则，我们显式定义并记录（**不得事后为凑结果修改**）：

1. **某一流在整个 update 内没有有效位置**（例如全被接受、或全被截断）：
   该分量没有定义。处理：**丢弃该分量并把分母按剩余 λ 重新归一**
   （即只剩接受流时 `L = L_acc`），并在日志中标记 `streams_present`。
   不把空流当作 0 加进去稀释另一流——那会因「恰好没有拒绝」而整体缩小梯度，
   属于数据相关的隐式缩放。
2. **两流都为空**：该 update 贡献 0 loss，但仍计入 `updates`、不计入有效 anchor 统计，
   并在日志中标记。
3. **EOS / padding / 截断**：只统计 `prompt_len <= pos < min(seq_len, max_seq_len)` 范围内的
   block 位置；越过 EOS 或 `max_seq_len` 的位置一律不监督，不计入任何分母。
4. **`k` 的计数起点**：Eq 8/9 的 `k` 是 block 内 1-based offset，`w_k = γ^(k-1)` 使
   block 内第一个 token 权重为 1.0。第一处被拒 token 的 offset 为 `r_m + 1`。

## 4. 偏离论文的记录（各带理由）

| 偏离 | 理由 |
|---|---|
| **常数 lr（不用 cosine + warmup 0.05）** | 论文的 cosine 定义在「8 epochs × 16K prompts」的量级上。本轮每臂只有 50–100 updates、439 行视频，没有有意义的 epoch 结构；且 C1（continue-SFT）与 C2（OPD）必须用**逐项相同**的优化器才能把差异归因到 loss。项目既有基线（`train_head_video.py`、2×2 四臂）也都是常数 lr 3e-4。**记录为偏离。** |
| **teacher 前向精度 fp32（10.4）** | 论文未规定；由 §10.4 与本项目 B0 的实测决定（bf16 有 ~0.4% 目标值漂移）。 |
| **block=16 / tree b63k8 评测** | 论文主体是 EAGLE-3 与 DFlash 文本设置；本项目沿用 GLANCE 视频口径。 |

## 5. 对既有文档的修正

- 计划 §4 B1 第 5 条原文写「`w_k = 0.8^(k-1)`，accepted/rejected 两个 stream 等权并分别归一」
  —— 方向正确，**但需补两点**：(i) `w_k` **只用于拒绝流**，接受流是朴素均值；
  (ii) 「分别归一」= 论文 Eq 13 的形式，**与官方代码的池化归一不同**，须显式选择。
- 计划 §4 B1 未规定空流处理，现由 §3 补齐。
- 2×2 报告把「rejected reverse-KL stream 为空」写成与论文目标的差异，方向正确；
  本文件进一步定位到**官方代码本身用的是采样估计量**，全词表 KL 是论文而非代码的形态。
